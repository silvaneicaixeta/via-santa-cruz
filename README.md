# Via Santa Cruz

Site institucional da **Via Santa Cruz** — *Projetos que nascem para servir.*

## Estrutura
- `index.html` — página inicial
- `projetos.html` — apresentação dos projetos
- `agenda.html` — Agenda Via Santa Cruz
- `agenda.js` — consulta, busca e filtros da Agenda
- `sobre.html` — proposta e princípios da Via Santa Cruz
- `idealizador.html` — apresentação discreta do idealizador
- `styles.css` — identidade visual e responsividade
- `script.js` — navegação móvel
- `assets/` — símbolo e ilustrações vetoriais
- `CNAME` — domínio personalizado `viasantacruz.com.br`
- `site.webmanifest`, `robots.txt` e `sitemap.xml`

## Projetos
- Diretório: https://diretorio.viasantacruz.com.br
- Diante de Deus: https://diantededeus.viasantacruz.com.br
- Agenda: https://viasantacruz.com.br/agenda.html

## Agenda
A Agenda utiliza calendários públicos previamente autorizados do Google Calendar, sincronizados para uma camada própria da Via Santa Cruz. A interface pública lê o cache, evitando consultas diretas ao Google a cada acesso.

## Publicação
A página é publicada pelo GitHub Pages a partir da branch `main`, na raiz do repositório.
